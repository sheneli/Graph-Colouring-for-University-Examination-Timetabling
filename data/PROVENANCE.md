# Data provenance

## Source

The experiments use the **Toronto (Carter) examination timetabling benchmark, version I**: 13 real
instances from Carter, Laporte and Lee (1996), with the version naming of Qu et al. (2009). The
canonical host is the University of Nottingham dataset page. It could not be reached from the build
environment, so the files were taken from a public GitHub mirror:

`https://raw.githubusercontent.com/Sajib-006/Eaxam-Scheduler-Using-Graph-Coloring-and-Kempe-Chain/master/Toronto/`

Each instance has two files: `.crs` (exam id and enrolment count) and `.stu` (one line per student,
listing that student's exams).

## Integrity

- `data/SHA256SUMS` records the SHA-256 of every file used in the reported experiments.
- `python scripts/get_data.py` downloads any missing file and verifies all checksums.
- Statistics computed by `examrepair.io.load_toronto` (below) match the published version-I
  figures for exams, students and enrolments. A mismatch indicates a different file version.

## Licence

No licence statement was found on the mirror or the dataset page. The raw files are therefore
**not** committed to the repository (`.gitignore` excludes `data/raw/`). Anyone reproducing the
work should download them with the script above or from the Nottingham page.

## Synthetic data

The scaling experiment uses synthetic instances generated by `examrepair.streams.synthetic_instance`
from fixed seeds (`configs/experiment.toml`, `configs/experiment_v2.toml`). No synthetic data is
stored; it is regenerated on every run.

## Late-enrolment streams

Late enrolments are simulated by holding out a random subset of real enrolments and replaying them
after the initial timetable is published (`examrepair.streams.holdout_stream`). Seeds 0–9 (v1) and
10–19 (Addendum A) fully determine every stream.
